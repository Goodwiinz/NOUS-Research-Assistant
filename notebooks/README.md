# Notebooks

Exploratory notebooks, sample inputs and recorded plots from the early RAG system: clustering and corpus analysis (`clustering_analysis*.ipynb`, `corpus_analysis.ipynb` and the PNG plots), RAG demos (`rag_*_demo*.ipynb`, `quick_rag_test.ipynb`, `presentation_walkthrough.ipynb`, `rag_analysis_presentation.ipynb`), a dataset demo (`dataset_integration_demo.ipynb`), and sample documents (`quantum_basics.txt`, `test_ai_doc.txt`, `test_documents/`).

The loose Python scripts here (`COMPLETE_AUTH_TEST.py`, `complete_auth_upload_test.py`, `auth_fix.py`, `processing_status_fix.py`, `workers_test_snippet.py`) are stale one-off fix and smoke-test snippets from earlier debugging sessions. They are not part of any supported runtime, test path or CI gate, and they assume an earlier auth and processing layout; do not run them against a shared environment. Notebook outputs and plots are recorded evidence for the code revision and environment that produced them, not current behavior.

Nothing here has been deleted or rewritten. See [`AGENTS.md`](AGENTS.md) for the rules on editing notebooks, and [current engineering contracts](../docs/engineering/README.md) for supported workflows.
