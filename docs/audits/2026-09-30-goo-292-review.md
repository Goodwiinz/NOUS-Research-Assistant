### Why no draft persisted (dev defect)

`_require_passing_citation_review` rejects any `exact`/`minor` verdict whose `location == "source excerpt"`. `evidence_selection.evidence_location` returns `"source excerpt"` whenever the verifier's `evidence` string is not a verbatim substring of a source passage. The live verifier returns a narrative (`The excerpt explicitly states: “…” It also explains …`), not a bare quote. So **all 12 verdicts** have `location="source excerpt"` and the gate fails closed. This happens even before the two `major` verdicts would have blocked. Both 09-29 and 09-30 candidates show the same pattern. As long as the verifier returns prose-wrapped evidence, no multi-document draft can persist on dev.
