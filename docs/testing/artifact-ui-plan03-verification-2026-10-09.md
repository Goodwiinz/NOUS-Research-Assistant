## Limits

The legacy popstate fallback restores the current editor with pushState, replacing forward entries. Modern Navigation API traversal preserves native history. Interactive HTML supports self-contained nonce-authorized script tags with addEventListener; inline handler attributes, remote assets/packages and arbitrary networking remain unsupported. PDF source is capped at 2MiB and rasterization can fall back to download.

Local component/browser checks do not establish global WCAG conformance, live authenticated backend end-to-end behavior, hosted CodeQL/integration/golden replay results, or deployment readiness. Backend behavior is covered by the dependency PR's separate proof. The final local wrapper runs with `--skip-tests`, explicitly preserving that boundary instead of treating the full backend suite as rerun.
