# `nous --rc` Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** One command, `nous --rc`, that signs in to web NOUS, lets the user pick or create a project, pairs this computer for Local Codex with read access to the project's documents, registers the current folder and runs the bridge; and a bridge that accepts Codex `0.161.0` as well as `0.153.4`.

**Architecture:** Two PRs. PR 1 replaces the single Codex version pin in `packages/harness-bridge/src/adapters/codex.ts` with a list of tested versions and renames the vendored schema folder. PR 2 adds an `rc` subcommand to the same package's CLI (`src/cli.ts`), built from the existing `connect`, `addWorkspace` and `runBridge`, plus a `--rc` branch in the repo-root `nous` launcher. No backend or frontend changes. Design: [`2026-10-12-nous-rc-design.md`](2026-10-12-nous-rc-design.md).

**Tech Stack:** TypeScript on Node 24 run through `tsx` (no build step), `node:test` with fixture fakes (no network, no real Codex), pnpm 10.18.2, bash for the launcher.

```ts
/**
 * Browser CLI login: start a session, print the link and the code the user
 * types on that page, poll until approved. Returns the CLI access token.
 */
export async function login(base: string, options: ClientOptions): Promise<string> {
  const fetchFn = options.fetchFn ?? fetch;
  const announce = options.announce ?? console.log;
  const started = await request(fetchFn, base, "/cli-auth/start", undefined, {});
  if (
    typeof started.session_id !== "string" ||
    typeof started.poll_token !== "string" ||
    typeof started.browser_url !== "string"
  )
    throw new Error("invalid CLI login response");
  // GOO-403: the link no longer carries the code; the user must type it on the
  // approval page, so a login response without a printable code is unusable.
  // The format check also keeps server-supplied text from injecting terminal
  // control sequences.
  if (
    typeof started.verification_code !== "string" ||
    !/^[A-Z0-9]{4}-[A-Z0-9]{4}$/.test(started.verification_code)
  )
    throw new Error("invalid CLI login response");
  announce(
    `Authorize CLI login in your browser: ${started.browser_url}\nType this code on that page: ${started.verification_code}`,
  );
  const auth = await poll(
    () =>
      request(
        fetchFn,
        base,
        `/cli-auth/status/${encodeURIComponent(started.session_id)}`,
        undefined,
        undefined,
        { "X-CLI-Poll-Token": started.poll_token },
      ),
    options,
  );
  if (typeof auth.token !== "string" || !auth.token)
    throw new Error("missing CLI access token");
  return auth.token;
}
```

/** Terminal-safe display name: NOUS project names are user data. */
const plain = (value: string): string =>
  value.replace(/[\p{Cc}\p{Cf}  ]/gu, "");
/** A `/projects` page, or null when NOUS no longer accepts the CLI token. */
async function listProjects(
  fetchFn: typeof fetch,
  base: string,
  token: string,
): Promise<RcProject[] | null> {
  const response = await fetchFn(`${base}/projects?limit=50`, {
    headers: { Authorization: `Bearer ${token}` },
    redirect: "error",
    signal: AbortSignal.timeout(15_000),
  });
  if (response.status === 401) return null;
  if (!response.ok)
    throw new Error(`NOUS request failed (${response.status}) /projects`);
  const data: unknown = await response.json().catch(() => null);
  if (!record(data) || !Array.isArray(data.projects))
    throw new Error("invalid NOUS response");
  return data.projects.flatMap((p: unknown): RcProject[] =>
    record(p) && uuid(p.id) && typeof p.name === "string"
      ? [
          {
            id: p.id,
            name: plain(p.name),
            ...(typeof p.document_count === "number"
              ? { documentCount: p.document_count }
              : {}),
          },
        ]
      : [],
  );
}
/** Create a project, asking which workspace only when the user has several. */
async function createProject(
  fetchFn: typeof fetch,
  base: string,
  token: string,
  prompt: (question: string) => Promise<string>,
  announce: (message: string) => void,
): Promise<RcProject> {
  let name = "";
  while (!name) name = plain(await prompt("Project name: ")).trim();
  // Projects live in a NOUS workspace (not a local folder); v2 is a sibling of v1.
  const workspaces = await fetchFn(`${base.replace(/\/v1$/, "/v2")}/workspaces`, {
    headers: { Authorization: `Bearer ${token}` },
    redirect: "error",
    signal: AbortSignal.timeout(15_000),
  });
  if (!workspaces.ok)
    throw new Error(`NOUS request failed (${workspaces.status}) /workspaces`);
  const list: unknown = await workspaces.json().catch(() => null);
  const choices = (Array.isArray(list) ? list : []).flatMap((w: unknown) =>
    record(w) && uuid(w.id) && typeof w.name === "string"
      ? [{ id: w.id, name: plain(w.name) }]
      : [],
  );
  if (!choices.length) throw new Error("no NOUS workspace to create the project in");
  let workspace = choices[0];
  if (choices.length > 1) {
    announce(["Workspaces:", ...choices.map((w, i) => `  ${i + 1}) ${w.name}`)].join("\n"));
    for (;;) {
      const index = Number.parseInt(await prompt(`Pick a workspace [1-${choices.length}]: `), 10);
      if (Number.isInteger(index) && index >= 1 && index <= choices.length) {
        workspace = choices[index - 1];
        break;
      }
      announce("Not a listed choice.");
    }
  }
  const created = await request(fetchFn, base, "/projects", token, {
    workspace_id: workspace.id,
    name,
  });
  if (!uuid(created.id)) throw new Error("invalid NOUS response");
  return { id: created.id, name, documentCount: 0 };
}
/** Numbered picker: a listed project by number, or `n` for a new one. */
async function pickProject(
  projects: RcProject[],
  prompt: (question: string) => Promise<string>,
  announce: (message: string) => void,
  create: () => Promise<RcProject>,
): Promise<RcProject> {
  announce(
    [
      "Your projects:",
      ...projects.map(
        (p, i) =>
          `  ${i + 1}) ${p.name}${p.documentCount !== undefined ? `  ${p.documentCount} docs` : ""}`,
      ),
      "  n) New project",
    ].join("\n"),
  );
  const range = projects.length ? `1-${projects.length}, n` : "n";
  for (;;) {
    const answer = (await prompt(`Pick a project [${range}]: `)).trim().toLowerCase();
    if (answer === "n") return create();
    const index = Number.parseInt(answer, 10);
    if (Number.isInteger(index) && index >= 1 && index <= projects.length)
      return projects[index - 1];
    announce("Not a listed choice.");
  }
}
export type RcOptions = ClientOptions & {
  apiUrl: string;
  /** The folder Codex works in: the caller's current directory. */
  dir: string;
  label?: string;
  prompt: (question: string) => Promise<string>;
  /** Checks the local Codex before anything else; resolves with its version. */
  probe: () => Promise<{ version: string }>;
  /** Runs the bridge in the foreground until the caller stops it. */
  run: (stateDir: string) => Promise<void>;
};
/**
 * `nous --rc`: sign in, pick or create a project, pair this computer for
 * harness runs with read access to the project's documents, register the
 * current folder, run. Reuses the stored pairing when it is for the same
 * project; a different project replaces it (one pairing per computer).
 */
export async function rc(options: RcOptions): Promise<void> {
  const base = apiBase(options.apiUrl);
  const fetchFn = options.fetchFn ?? fetch;
  const announce = options.announce ?? console.log;
  // Codex first, so the user never approves a pairing that cannot run.
  const { version } = await options.probe();
  announce(`NOUS: ${base}`);
  const store = new CredentialStore(options.stateDir);
  const previous = storedConnection(await store.readLocal("connection").catch(() => null));
  let sameApi = false;
  try {
    sameApi = previous !== null && apiBase(previous.apiUrl) === base;
  } catch {
    // An unparsable stored URL is a different NOUS.
  }
  // The stored CLI token first; a 401 means sign in again, once.
  let token: string | undefined = sameApi && previous !== null
    ? await store.load(previous.credentialHandle).then((c) => c.accessToken).catch(() => undefined)
    : undefined;
  let projects = token === undefined ? null : await listProjects(fetchFn, base, token);
  if (projects === null) {
    token = await login(base, options);
    projects = await listProjects(fetchFn, base, token);
    if (projects === null) throw new Error("NOUS refused the new sign-in");
  }
  const signedIn = token;
  announce("Signed in.");
  const project = await pickProject(projects, options.prompt, announce, () =>
    createProject(fetchFn, base, signedIn, options.prompt, announce),
  );
  if (sameApi && previous?.projectId !== undefined && previous.projectId !== project.id)
    announce(
      `Your approval for project ${previous.projectId} stays active until you revoke it under Settings → Connected devices (/integrations/devices) in NOUS.`,
    );
  try {
    await connect({
      stateDir: options.stateDir,
      fetchFn,
      announce,
      delay: options.delay,
      apiUrl: base,
      projectId: project.id,
      label: options.label ?? hostname(),
      tools: true,
      accessToken: signedIn,
    });
    await addWorkspace({
      stateDir: options.stateDir,
      fetchFn,
      // addWorkspace's own notice is about write roots; rc prints its summary below.
      announce: () => {},
      root: options.dir,
    });
  } catch (error) {
    // The harness and tools gateways answer 503 while the server flags are off.
    if (error instanceof Error && /\(503\)/.test(error.message))
      throw new Error("Local Codex is turned off on this NOUS server");
    throw error;
  }
  const root = await realpath(options.dir);
  announce(`Connected: "${project.name}" ↔ ${root}  (Codex ${version})`);
  announce(
    `In a chat for this project on NOUS, choose Local Codex → this computer → ${basename(root)}.\nPress Ctrl-C to stop.`,
  );
  await options.run(options.stateDir);
}

2. Signs in with the browser link + code flow, or reuses the stored CLI token.
3. Lists your projects with `n) New project` (creates it in your workspace; asks which only if you have several).
4. Pairs this computer with `harness:execute` + `tools:read`, reusing the stored pairing for the same project (no browser) and replacing it for a different one (browser approval, plus a note on where to revoke the old consent).
5. Registers the current folder and runs the bridge until Ctrl-C.

Also: `login()` is extracted from `connect`, which can now take an `accessToken`; the `nous` launcher resolves its own symlink, checks for Node 24 and passes the current folder as `--root`. No backend or frontend changes. Design: `docs/plans/2026-10-12-nous-rc-design.md`; plan: `docs/plans/2026-10-12-nous-rc.md`.
