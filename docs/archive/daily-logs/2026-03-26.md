## Agent v2 Implementation (feature/agent-v2)

Major implementation session — 6 of 10 phases completed for the Agent v2 plan (`docs/plans/2026-03-25-agent-v2-plan.md`).

### Completed Phases

**Phase 1: Foundation (Tasks 1-3)**

- Extended `AgentState` with v2 fields: `plan`, `reflection_count`, `compaction_count`, `intent_confidence`, `last_error_info`
- Created `error_recovery.py`: `ToolError` taxonomy (transient/recoverable/user_fixable/fatal), `retry_transient` with exponential backoff, per-tool suggestion map
- Wired into `_execute_single_tool` and `tool_node` — transient retries, consecutive error reset on success

**Phase 2: LLM Intent Classifier (Tasks 4-5)**

- Created `classifier.py`: gpt-4o-mini structured output with keyword fallback
- Few-shot examples for known confusions (e.g., "graph neural networks" → research, not knowledge_graph)
- Wired into `intent_classifier_node` replacing keyword-only classification

**Phase 3: Context Compactor (Task 6)**

- Created `compactor.py`: token-based triggering (~8000 threshold), UUID/arXiv ID extraction, `[Compacted]` prefix, ID preservation validation
- `make_compactor_node()` factory for graph integration

**Phase 4: Adaptive Planner (Task 7)**

- Created `planner.py`: complexity gating (gpt-4o-mini), plan generation (gpt-4o), advisory only
- `make_planner_node()` — skips if plan exists or step_count < 3

**Phase 5: Reflection Gate (Task 8)**

- Created `reflection.py`: severity-based routing (minor→proceed, major→revise), max 2 rounds
- Only fires for research and writing intents

**Phase 7: Persistent Memory (Tasks 13-14)**

- Alembic migration for `agent_memories` table (PG + Qdrant dual storage)
- Created `memory_store.py`: save/search/update_access/cleanup_stale/extract_insights
- Graceful degradation if Qdrant unavailable
