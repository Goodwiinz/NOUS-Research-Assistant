## Review Focus

- A stale completion racing an accepted cancellation must not convert STOPPING to success; test both transaction orderings in package 1.
- A reused tool-call ID from a different user/thread or with different arguments must not reveal a stored result or execute another effect; test package 2 scope and fingerprint mismatches.
